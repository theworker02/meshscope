# meshscope

Mesh and reshape scope text streams with deterministic transforms.

**Site:** https://theworker02.github.io/meshscope/

## Install / run

```bash
git clone https://github.com/theworker02/meshscope.git
cd meshscope
node src/cli.js
node --test
```
